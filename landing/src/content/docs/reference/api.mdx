## `UruFacturaClient` / `IUruFacturaClient`

El cliente. Es thread-safe: registralo como singleton (como `IUruFacturaClient` para poder mockearlo).

### Constructor

```csharp
public UruFacturaClient(
    UruFacturaConfig config,
    IUruFacturaStore? store = null,      // por defecto InMemoryStore
    HttpClient? httpClient = null,       // p. ej. de IHttpClientFactory
    IDgiClient? dgiClient = null,        // transporte propio (tests, proxy)
    TimeProvider? reloj = null)          // reloj de las fechas fiscales
```

Valida la configuración (`UruFacturaException`) y carga el certificado (`FirmaDigitalException`). Con un `httpClient` propio, su handler debe tener el certificado de cliente TLS y la validación del servidor configurados; no se combina con `dgiClient`.

### Métodos

| Método | Descripción |
|--------|-------------|
| `Task RegistrarCaeAsync(Cae cae, CancellationToken ct = default)` | Registra un CAE (o actualiza uno existente: mismo tipo, serie y comienzo de rango). Lo valida: `CaeException` si los datos no son correctos |
| `Task<IReadOnlyList<Cae>> ObtenerCaesAsync(CancellationToken ct = default)` | Los CAE con su último número usado |
| `Task<IReadOnlyList<string>> ObtenerAdvertenciasCaeAsync(int diasAlertaVencimiento = 7, decimal porcentajeAlertaUso = 80m, CancellationToken ct = default)` | CAE vencidos, agotados, por vencer o con el rango casi usado |
| `IReadOnlyList<string> Validar(Cfe cfe)` | Errores que impedirían emitir (vacía si es válido). No reserva números |
| `Task<CfeEmitido> EmitirAsync(Cfe cfe, CancellationToken ct = default)` | Valida (`CfeValidationException`, sin consumir números), reserva el próximo número del CAE vigente (`CaeException` si no hay), genera el XML, lo firma y lo registra en el almacenamiento. No envía |
| `Task<AcuseSobre> EnviarAsync(CfeEmitido cfe, CancellationToken ct = default)` | Envía el CFE en un sobre `EnvioCFE`. El acuse indica si la DGI **recibió el sobre** |
| `Task<AcuseSobre> EnviarAsync(IReadOnlyCollection<CfeEmitido> cfes, CancellationToken ct = default)` | De 1 a 250 CFE en un sobre |
| `Task<EstadoEnvio> ConsultarEnvioAsync(AcuseSobre acuse, CancellationToken ct = default)` | Resultado de cada comprobante del sobre; actualiza su `EstadoDgi` y lo guarda. `InvalidOperationException` si el sobre no fue recibido |
| `Task<EstadoComprobante> ConsultarCfeAsync(CfeEmitido cfe, CancellationToken ct = default)` | Estado de un CFE (servicio `ws_consultas`); actualiza su `EstadoDgi` y lo guarda |
| `Task<AcuseReporte> EnviarReporteDiarioAsync(DateOnly fecha, int secEnvio = 0, CancellationToken ct = default)` | Reporte diario firmado con los CFE emitidos en la fecha, tomados del almacenamiento. `secEnvio` 0 el primero, 1 si se reenvía, … |

## `UruFacturaConfig`

```csharp
public sealed record UruFacturaConfig
{
    public Emisor Emisor { get; init; }
    public Ambiente Ambiente { get; init; }                 // default: Homologacion
    public string? RutaCertificado { get; init; }           // o Certificado
    public string? PasswordCertificado { get; init; }
    public X509Certificate2? Certificado { get; init; }     // ya cargado (Key Vault, HSM); prioridad sobre la ruta
    public AlgoritmoFirma AlgoritmoFirma { get; init; }     // default: Sha256
    public string? UrlEnvio { get; init; }                  // obligatoria en Producción
    public string? UrlConsultas { get; init; }              // obligatoria en Producción
    public TimeSpan Timeout { get; init; }                  // default: 30 s
    public bool OmitirValidacionSsl { get; init; }          // default: false; nunca en Producción
    public decimal? ValorUnidadIndexada { get; init; }      // activa el tope de 5.000 UI de los e-Tickets

    public IReadOnlyList<string> Validar();                 // errores (vacía si es válida)
}
```

`ToString()` no muestra la contraseña. Ver [Configuración](../../getting-started/configuration/).

### `Emisor`

| Propiedad | Tipo | Descripción |
|-----------|------|-------------|
| `Rut` | `string` | 12 dígitos con dígito verificador válido |
| `RazonSocial` | `string` | Hasta 150 caracteres |
| `DomicilioFiscal`, `Ciudad`, `Departamento` | `string` | Hasta 70 / 30 / 30 caracteres |
| `NombreComercial`, `Giro` | `string?` | Hasta 30 / 100 |
| `CodigoSucursal` | `int` | `CdgDGISucur` (1-9999, default 1) |
| `Sucursal` | `string?` | `EmiSucursal` (hasta 20) |
| `Telefonos` | `IReadOnlyList<string>` | Hasta 2 |
| `Correo`, `InfoAdicional` | `string?` | Hasta 80 / 150 |
| `FechaIncorporacion`, `UrlVerificacion` | `string?` | Leyendas de la representación impresa |

## Modelos del comprobante

Records inmutables: se arman con inicializadores y se modifican con `with`. Las colecciones son `IReadOnlyList<T>` y se asignan con `[ … ]`.

### `Cfe`

```csharp
public sealed record Cfe(TipoCfe Tipo)
```

| Propiedad | Tipo | Descripción |
|-----------|------|-------------|
| `Tipo` | `TipoCfe` | Tipo de comprobante |
| `FechaEmision` | `DateOnly?` | Si se omite, la fecha de Uruguay al emitir |
| `Emisor` | `Emisor?` | Reemplaza al de la configuración (mismo RUT), p. ej. otra sucursal |
| `Receptor` | `Receptor?` | Obligatorio en e-Factura, exportación y e-Resguardo |
| `Mandante` | `Mandante?` | Obligatorio en venta por cuenta ajena |
| `IndTraslado` | `IndTraslado?` | Obligatorio en e-Remito |
| `ClausulaVenta`, `ModalidadVenta`, `ViaTransporte` | `string?`, `int?`, `int?` | Datos de exportación |
| `FormaPago` | `FormaPago` | `Contado` (default) o `Credito` |
| `Moneda` / `TipoCambio` | `Moneda` / `decimal?` | `TipoCambio` es obligatorio si la moneda no es el peso |
| `NroInterno`, `InfoAdicional` | `string?` | Hasta 50 / 150 caracteres |
| `FechaVencimiento` | `DateOnly?` | Vencimiento del pago |
| `Detalle` | `IReadOnlyList<LineaDetalle>` | Al menos una línea |
| `DescuentosRecargos` | `IReadOnlyList<DescuentoRecargoGlobal>` | Hasta 20; cambian la base del IVA |
| `MediosPago` | `IReadOnlyList<MedioPago>` | Hasta 40 |
| `Referencias` | `IReadOnlyList<RefCfe>` | Obligatorias en las notas (hasta 40) |

`Totales CalcularTotales()` calcula los totales (IVA mínimo 10 %, básico 22 %) con la precisión del XML.

### `LineaDetalle`

| Propiedad | Tipo | Descripción |
|-----------|------|-------------|
| `NombreItem` | `string` | Hasta 80 caracteres (obligatorio salvo en e-Resguardo) |
| `Cantidad` | `decimal` | Mayor a cero (3 decimales en el XML) |
| `PrecioUnitario` | `decimal` | Sin IVA (6 decimales). Los remitos no llevan precio |
| `IndFactIva` | `TipoIva` | Default `Basico`; en exportación se informa `IndFact` 10 |
| `UnidadMedida` | `string?` | Hasta 4 caracteres; si se omite, `N/A` |
| `Descripcion` | `string?` | Hasta 1000 caracteres |
| `DescuentoMonto`, `DescuentoPorcentaje`, `RecargoMonto` | `decimal`, `decimal?`, `decimal` | El monto tiene prioridad sobre el porcentaje |
| `Codigos` | `IReadOnlyList<CodigoItem>` | Hasta 5 (`Tipo`, `Codigo`) |
| `Retenciones` | `IReadOnlyList<RetencionPercepcion>` | Solo e-Resguardo, de 1 a 5 (`Codigo`, `Tasa`, `MontoSujeto`, `Valor`, `InfoAdicional`) |
| `MontoTotal` | `decimal` | *(calculado)* Cantidad × Precio − Descuento + Recargo |

Las líneas se numeran por su posición.

### `Receptor`

| Propiedad | Tipo | Descripción |
|-----------|------|-------------|
| `Documento` | `string?` | En e-Factura, un RUT uruguayo válido |
| `TipoDocumento` | `TipoDocumentoReceptor` | Default `Rut` |
| `CodigoPais` | `string` | ISO alfa-2 (default `UY`); si no es `UY`, se informa como documento extranjero |
| `RazonSocial`, `Direccion`, `Ciudad`, `Departamento`, `Pais` | `string?` | En e-Remito, razón social, dirección y ciudad son obligatorias |
| `CodigoPostal`, `InfoAdicional`, `CompraId`, `LugarDestinoEntrega` | `string?` | Opcionales |

## `CfeEmitido`

El resultado de `EmitirAsync`. Los datos fiscales son inmutables; el estado ante la DGI se actualiza al enviar y consultar.

| Propiedad | Tipo | Descripción |
|-----------|------|-------------|
| `Documento` | `Cfe` | Contenido emitido, con `FechaEmision` y `Emisor` resueltos |
| `Tipo`, `Serie`, `Numero`, `FechaEmision`, `Emisor` | | Identificación |
| `Cae` | `Cae` | CAE con el que se numeró |
| `Totales` | `Totales` | Totales informados |
| `Xml` | `string` | XML firmado (conservarlo durante el plazo legal) |
| `FechaFirma` | `DateTimeOffset` | `TmstFirma` |
| `CodigoSeguridad` | `string` | `DigestValue` de la firma; los primeros 6 caracteres se imprimen |
| `UrlQr` | `string` | Contenido del código QR |
| `IdReceptorDgi`, `TokenDgi` | `string?` | Sobre en que se envió |
| `EstadoDgi`, `MensajeDgi` | `string?` | `AE`, `BE`, `CE`, `FE` y sus motivos; `null` sin resultado |
| `AceptadoPorDgi`, `Enviado` | `bool` | `EstadoDgi == "AE"` / se envió en un sobre recibido |

## Costuras

| Interfaz | Implementaciones | Para qué |
|----------|------------------|----------|
| `IUruFacturaClient` | `UruFacturaClient` | Inyección y mocks en tu aplicación |
| `IUruFacturaStore` | `InMemoryStore` (default), `EfUruFacturaStore<TContext>` | CAE, numeración atómica, número de envío y CFE emitidos |
| `IDgiClient` | SOAP con WS-Security (interno) | Transporte hacia la DGI (tests, proxy) |

<Aside type="note">
  El XML, la firma, el sobre, el reporte y el cliente SOAP son internos: se reemplaza el comportamiento a través de estas tres interfaces, no heredando. Para firmar con Key Vault o un HSM, pasá el certificado en `UruFacturaConfig.Certificado`.
</Aside>

### `IUruFacturaStore`

```csharp
ValueTask GuardarCaeAsync(Cae cae, CancellationToken ct = default);            // upsert; UltimoNroUsado nunca retrocede
ValueTask<IReadOnlyList<Cae>> ListarCaesAsync(CancellationToken ct = default);
ValueTask<Cae?> ReservarNumeroAsync(TipoCfe tipo, DateOnly hoy, CancellationToken ct = default);  // atómico
ValueTask<long> ReservarIdEnvioAsync(CancellationToken ct = default);           // creciente y único entre instancias
ValueTask GuardarCfesAsync(IReadOnlyCollection<CfeEmitido> cfes, CancellationToken ct = default);
ValueTask<IReadOnlyList<CfeEmitido>> ListarCfesAsync(DateOnly fechaEmision, CancellationToken ct = default);
```

`InMemoryStore.DiasRetencionCfe` (default 7) limita cuántos días de CFE conserva. `EfUruFacturaStore` reserva con compare-and-swap y reintenta hasta `MaxIntentos` (default 100); sus entidades (`CaeEntity`, `CfeEntity` con `ToCfeEmitido()`) son públicas para consultas propias.

## Excepciones

| Excepción | Cuándo |
|-----------|--------|
| `UruFacturaException` | Base; configuración inválida, sobre fuera de 1-250 CFE |
| `CfeValidationException` | El CFE no es válido (`Errors`) |
| `CaeException` | CAE inválido al registrarlo, o no hay CAE vigente con números |
| `FirmaDigitalException` | Certificado inexistente, contraseña incorrecta, sin clave privada; falla de firma |
| `DgiCommunicationException` | Red, timeout, SOAP Fault o HTTP sin acuse (`CodigoRespuesta`, `Respuesta`) |
| `PdfGenerationException` | Falla del PDF (`UruFactura.Pdf`) |
