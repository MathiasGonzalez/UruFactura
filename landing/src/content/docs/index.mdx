## ¿Por qué UruFactura?

<CardGrid stagger>
  <Card title="Simplicidad ante todo" icon="pencil">
    Describís el comprobante; UruFactura lo valida, lo numera, lo firma y lo envía. Un solo namespace y un cliente.
  </Card>
  <Card title="Firma Digital incluida" icon="approve-check-circle">
    Firma XML y WS-Security con certificados `.p12` / `.pfx` o de Key Vault/HSM, validadas contra los XSD y WSDL oficiales de la DGI.
  </Card>
  <Card title="Todos los tipos de CFE" icon="document">
    e-Ticket, e-Factura, e-Remito, exportación, notas de crédito/débito, e-Resguardo, e-Boleta de entrada, cuenta ajena y contingencia, con los 17 indicadores de facturación, retenciones y percepciones, y los CAE especiales (exonerados, IVA mínimo, Monotributo).
  </Card>
  <Card title="Listo para producción" icon="laptop">
    Numeración atómica entre instancias con EF Core, reporte diario según el formato v13.2, intercambio con otros emisores electrónicos y PDF A4/térmico con QR.
  </Card>
</CardGrid>

## Tu primer e-Ticket

```csharp
using UruFactura;

// 1. Configurar el cliente
var config = new UruFacturaConfig
{
    Emisor = new Emisor
    {
        Rut             = "219999820013",
        RazonSocial     = "Mi Empresa S.A.",
        DomicilioFiscal = "Av. 18 de Julio 1234",
        Ciudad          = "Montevideo",
        Departamento    = "Montevideo",
    },
    Ambiente            = Ambiente.Homologacion,
    RutaCertificado     = "/ruta/al/certificado.p12",
    PasswordCertificado = Environment.GetEnvironmentVariable("CERT_PASSWORD"),
};

using var client = new UruFacturaClient(config);

// 2. Registrar el CAE que entregó la DGI
await client.RegistrarCaeAsync(new Cae
{
    NumeroAutorizacion = "90110001945",
    TipoCfe            = TipoCfe.ETicket,
    Serie              = "A",
    RangoDesde         = 1,
    RangoHasta         = 1000,
    FechaVencimiento   = new DateOnly(2027, 12, 31),
});

// 3. Emitir (valida, numera, firma) y enviar
var emitido = await client.EmitirAsync(new Cfe(TipoCfe.ETicket)
{
    Detalle = [new LineaDetalle { NombreItem = "Servicio de consultoría", Cantidad = 1, PrecioUnitario = 5000m }],
});
var acuse = await client.EnviarAsync(emitido);   // AS = sobre recibido

// 4. Resultado del comprobante (AE = aceptado) y PDF (paquete UruFactura.Pdf)
if (acuse.Recibido)
{
    await client.ConsultarEnvioAsync(acuse);
    if (emitido.AceptadoPorDgi)
        await File.WriteAllBytesAsync("eticket.pdf", CfePdf.GenerarA4(emitido));
}
```

## Tipos de CFE soportados

| Código | Tipo |
|--------|------|
| 101 / 102 / 103 | e-Ticket y sus notas de crédito/débito |
| 111 / 112 / 113 | e-Factura y sus notas |
| 121 / 122 / 123 | e-Factura de Exportación y sus notas |
| 124 | e-Remito de Exportación |
| 181 | e-Remito |
| 182 | e-Resguardo |
| 131-133, 141-143 | Venta por cuenta ajena |
| 2xx | Comprobantes de contingencia |
