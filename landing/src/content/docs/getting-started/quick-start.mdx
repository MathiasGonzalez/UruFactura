En esta guía vas a emitir y enviar tu primer e-Ticket a la DGI (en homologación).

## El flujo

```
Configurar → Registrar CAE → Emitir (valida, numera, firma) → Enviar → Consultar resultado → PDF
                                                         … y al cierre del día: Reporte diario
```

---

## Paso 1: Cliente

```csharp
using UruFactura;

var config = new UruFacturaConfig
{
    Emisor = new Emisor
    {
        Rut             = "219999820013",
        RazonSocial     = "Mi Empresa S.A.",
        DomicilioFiscal = "Av. 18 de Julio 1234",
        Ciudad          = "Montevideo",
        Departamento    = "Montevideo",
    },
    Ambiente            = Ambiente.Homologacion,
    RutaCertificado     = "/ruta/al/certificado.p12",
    PasswordCertificado = Environment.GetEnvironmentVariable("CERT_PASSWORD"),
};

using var client = new UruFacturaClient(config);
```

<Aside type="caution">
  Sin más parámetros, el cliente guarda la numeración **en memoria**: sirve para probar, pero si la aplicación se reinicia volvería a usar números. En producción pasale un almacenamiento durable (`store:`), como el de `UruFactura.EntityFrameworkCore`. Ver [Gestión de CAE](../../guides/cae-management/).
</Aside>

---

## Paso 2: Registrar el CAE

El CAE es el rango de números que la DGI autoriza para un tipo de CFE y una serie.

```csharp
await client.RegistrarCaeAsync(new Cae
{
    NumeroAutorizacion = "90110001945",   // CAE_ID entregado por la DGI
    TipoCfe            = TipoCfe.ETicket,
    Serie              = "A",
    RangoDesde         = 1,
    RangoHasta         = 1000,
    FechaVencimiento   = new DateOnly(2027, 12, 31),
});
```

---

## Paso 3: Emitir

`Cfe` describe el comprobante (es inmutable). `EmitirAsync` lo valida, le asigna el próximo número del CAE, arma el XML, lo firma y lo registra.

  ```csharp
  var emitido = await client.EmitirAsync(new Cfe(TipoCfe.ETicket)
  {
      Detalle =
      [
          new LineaDetalle { NombreItem = "Servicio de consultoría", Cantidad = 1, PrecioUnitario = 5000m, IndFactIva = TipoIva.Basico },
      ],
  });
  ```
  </TabItem>
  <TabItem label="e-Factura con receptor">

  </TabItem>

Si el CFE no es válido, `EmitirAsync` lanza `CfeValidationException` (con la lista en `Errors`) **sin consumir números**. Para revisar sin emitir: `client.Validar(cfe)`.

## Paso 4: Enviar y consultar el resultado

```csharp
// 1) La DGI acusa recibo del sobre (AS = recibido, BS/BA = rechazado)
var acuse = await client.EnviarAsync(emitido);
if (!acuse.Recibido)
{
    Console.WriteLine($"❌ Sobre rechazado [{acuse.Estado}]: {acuse.Mensaje}");
    return;
}

// 2) Resultado del comprobante (AE = aceptado, BE = rechazado, CE = observado)
var estado = await client.ConsultarEnvioAsync(acuse);
Console.WriteLine(emitido.AceptadoPorDgi
    ? "✅ Aceptado"
    : $"❌ [{emitido.EstadoDgi}]: {emitido.MensajeDgi}");
```

<Aside type="tip">
  Recibir el sobre (`AS`) no significa que el CFE fue aceptado: la DGI lo procesa y después informa el estado de cada comprobante. Si todavía no terminó, `estado.Procesado` es `false`: volvé a consultar más tarde (la DGI indica desde cuándo en `acuse.ConsultarDesde`).
</Aside>

---

## Paso 5: Representación impresa (PDF)

Con el paquete `UruFactura.Pdf`:

```csharp
await File.WriteAllBytesAsync($"eticket_{emitido.Numero:D8}.pdf", CfePdf.GenerarA4(emitido));      // A4
await File.WriteAllBytesAsync($"eticket_{emitido.Numero:D8}_80mm.pdf", CfePdf.GenerarTermico(emitido)); // ticket
```

## Reporte diario

La DGI exige enviar cada día un resumen de los CFE emitidos. Sale del almacenamiento del cliente (todo lo que se emitió con `EmitirAsync`):

```csharp
// Usá la fecha de Uruguay (HoraUruguay), no DateTime.Today: el servidor puede estar en UTC.
var reporte = await client.EnviarReporteDiarioAsync(HoraUruguay.Hoy().AddDays(-1));
Console.WriteLine($"Reporte diario: {reporte.Estado} ({reporte.CantidadCfe} CFE)");
```

<Aside type="caution">
  El Reporte Diario es **obligatorio**. Automatizalo con un job nocturno.
</Aside>
