## Requisitos previos

- **.NET 10 SDK** o superior ([descargar](https://dotnet.microsoft.com/download))
- Un **certificado digital** (`.p12` / `.pfx`) emitido por una CA reconocida por AGESIC y vinculado al RUT del emisor
- Un **CAE vigente** otorgado por la DGI para cada tipo de CFE que vayas a emitir

<Aside type="note">
  ¿Todavía no tenés el certificado o el CAE? Podés usar el ambiente de **Homologación** de la DGI para hacer pruebas. Consultá la [Guía de Certificación DGI](../../guides/dgi-certification/).
</Aside>

## Paquetes

| Paquete | Contenido | Cuándo |
|---------|-----------|--------|
| **`UruFactura`** | Emisión, firma, numeración con CAE, comunicación con la DGI, reporte diario e intercambio con otros emisores electrónicos. Sin dependencias de terceros | Siempre |
| **`UruFactura.Pdf`** | PDF A4, térmico (80 mm) y QR (FluentReport + SkiaSharp + ZXing) | Si imprimís o enviás el PDF |
| **`UruFactura.EntityFrameworkCore`** | Almacenamiento en base de datos: numeración durable y segura entre instancias, CFE emitidos para el reporte diario | En producción |

Los paquetes de EF Core no traen proveedor: agregá el de tu base (`Npgsql.EntityFrameworkCore.PostgreSQL`, `Microsoft.EntityFrameworkCore.SqlServer`, …).

## Configuración básica

<Steps>

1. **Importar el namespace** — todo lo público está en uno solo:

   ```csharp
   using UruFactura;
   ```

2. **Crear la configuración**

   ```csharp
   var config = new UruFacturaConfig
   {
       Emisor = new Emisor
       {
           Rut             = "219999820013",      // 12 dígitos, sin puntos ni guión
           RazonSocial     = "Mi Empresa S.A.",
           DomicilioFiscal = "Av. 18 de Julio 1234",
           Ciudad          = "Montevideo",
           Departamento    = "Montevideo",
       },
       Ambiente            = Ambiente.Homologacion, // ← Homologación para pruebas
       RutaCertificado     = "/ruta/al/certificado.p12",
       PasswordCertificado = Environment.GetEnvironmentVariable("CERT_PASSWORD"),
   };
   ```

   <Aside type="caution">
     Nunca guardes `PasswordCertificado` en texto plano en el código fuente. Usá variables de entorno, user secrets o un gestor de secretos.
   </Aside>

3. **Crear el cliente** — valida la configuración y carga el certificado (si algo está mal, falla acá y no al emitir):

   ```csharp
   using var client = new UruFacturaClient(config);
   ```

4. **Registrar los CAE**

   ```csharp
   await client.RegistrarCaeAsync(new Cae
   {
       NumeroAutorizacion = "90110001945",   // CAE_ID entregado por la DGI
       TipoCfe            = TipoCfe.ETicket,
       Serie              = "A",
       RangoDesde         = 1,
       RangoHasta         = 1000,
       FechaVencimiento   = new DateOnly(2027, 12, 31),
   });
   ```

</Steps>

## ASP.NET Core

El cliente es thread-safe: registralo como singleton. En producción, con el almacenamiento de EF Core:

```csharp
// Program.cs
var config = builder.Configuration.GetSection("UruFactura").Get<UruFacturaConfig>()!;

builder.Services.AddDbContextFactory<UruFacturaDbContext>(o => o.UseNpgsql(connectionString));
builder.Services.AddSingleton<IUruFacturaClient>(sp => new UruFacturaClient(
    config,
    store: new EfUruFacturaStore<UruFacturaDbContext>(sp.GetRequiredService<IDbContextFactory<UruFacturaDbContext>>())));
```

```json
// appsettings.json (la contraseña, por User Secrets o la variable UruFactura__PasswordCertificado)
{
  "UruFactura": {
    "Emisor": {
      "Rut": "219999820013",
      "RazonSocial": "Mi Empresa S.A.",
      "DomicilioFiscal": "Av. 18 de Julio 1234",
      "Ciudad": "Montevideo",
      "Departamento": "Montevideo"
    },
    "Ambiente": "Homologacion",
    "RutaCertificado": "/ruta/al/certificado.p12"
  }
}
```
