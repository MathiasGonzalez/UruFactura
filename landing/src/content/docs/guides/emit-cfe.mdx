## El modelo: `Cfe` → `CfeEmitido`

- **`Cfe`** describe el comprobante: tipo, receptor, detalle, referencias, etc. Es un record inmutable: se arma con un inicializador y se modifica con `with`.
- **`client.EmitirAsync(cfe)`** lo valida, le asigna el próximo número del CAE vigente, arma el XML, lo firma y lo registra en el almacenamiento (del que sale el reporte diario). No lo envía.
- **`CfeEmitido`** es el resultado: `Numero`, `Serie`, `Cae`, `Totales`, `Xml` firmado, `CodigoSeguridad`, `UrlQr` y el estado ante la DGI (`EstadoDgi`, `AceptadoPorDgi`).

Todos los tipos se crean igual: `new Cfe(TipoCfe.X) { … }`. Ver [Tipos de CFE](../../reference/cfe-types/).

---

## e-Ticket (101)

Para ventas al consumidor final (sin identificar al receptor):

```csharp
var eticket = await client.EmitirAsync(new Cfe(TipoCfe.ETicket)
{
    Detalle =
    [
        new LineaDetalle { NombreItem = "Servicio de consultoría", Cantidad = 2, PrecioUnitario = 3500m, IndFactIva = TipoIva.Basico }, // 22 %
        new LineaDetalle { NombreItem = "Viáticos", Cantidad = 1, PrecioUnitario = 1000m, IndFactIva = TipoIva.Exento },
    ],
});
```

`FechaEmision` es opcional: si se omite, es la fecha de Uruguay al emitir (no la del servidor).

## e-Factura (111)

Requiere identificar al receptor con su RUT:

```csharp
var efactura = await client.EmitirAsync(new Cfe(TipoCfe.EFactura)
{
    Receptor = new Receptor
    {
        Documento   = "214844360018",
        RazonSocial = "Empresa Compradora S.A.",
        Direccion   = "Bulevar España 2345",
        Ciudad      = "Montevideo",
    },
    Detalle = [new LineaDetalle { NombreItem = "Licencia de software anual", Cantidad = 1, PrecioUnitario = 50000m }],
});
```

## Notas de Crédito y Débito

Deben referenciar el CFE original, con su monto y moneda (obligatorios desde el formato CFE v25.01):

```csharp
var notaCredito = await client.EmitirAsync(new Cfe(TipoCfe.NotaCreditoETicket)
{
    Referencias =
    [
        new RefCfe
        {
            TipoCfe      = TipoCfe.ETicket,
            Serie        = "A",
            NroCfe       = 42,                        // número del CFE original
            FechaCfe     = new DateOnly(2025, 6, 15),
            MontoCfeRef  = 1220m,                     // total del CFE original
            MonedaCfeRef = Moneda.PesoUruguayo,       // moneda del CFE original
            Razon        = "Devolución parcial de mercadería",
        },
    ],
    Detalle = [new LineaDetalle { NombreItem = "Devolución - Producto X", Cantidad = 2, PrecioUnitario = 500m }],
});
```

## Validar antes de emitir

`EmitirAsync` valida antes de reservar el número: un CFE inválido lanza `CfeValidationException` (con la lista en `Errors`) sin consumir números. Para revisar sin emitir (por ejemplo, en el validador de un endpoint):

```csharp
IReadOnlyList<string> errores = client.Validar(cfe);
```

## Tipos de IVA

| Valor | Tasa | Uso común |
|-------|------|-----------|
| `TipoIva.Basico` | 22% | Servicios y bienes generales (default) |
| `TipoIva.Minimo` | 10% | Alimentos de primera necesidad, medicamentos |
| `TipoIva.Exento` | 0% | Bienes y servicios exonerados |
| `TipoIva.Suspendido` | — | IVA en suspenso (se informa en `MntIVaenSusp`) |

Los precios son **sin IVA**: el SDK calcula el impuesto y los totales con la misma precisión que el XML.

## Enviar a la DGI

```csharp
// 1) Sobre: la DGI responde AS (recibido) o BS/BA (rechazado)
var acuse = await client.EnviarAsync(eticket);        // o EnviarAsync([cfe1, cfe2, …]) con hasta 250
if (!acuse.Recibido)
{
    Console.WriteLine($"❌ Sobre rechazado [{acuse.Estado}]: {acuse.Mensaje}");
    return;
}

// 2) Resultado de cada comprobante: AE aceptado, BE rechazado, CE observado
var estado = await client.ConsultarEnvioAsync(acuse);
foreach (var cfe in acuse.Comprobantes)
    Console.WriteLine($"{cfe}: {cfe.EstadoDgi} {cfe.MensajeDgi}");
```

Tras un reinicio (cuando ya no tenés el acuse), `client.ConsultarCfeAsync(emitido)` consulta un comprobante suelto. Las consultas actualizan el estado en el almacenamiento.

---

## El XML firmado

`emitido.Xml` es el CFE firmado tal como se envía. La DGI exige conservarlo durante el plazo legal:

```csharp
await File.WriteAllTextAsync($"cfe/{emitido.Tipo}_{emitido.Serie}{emitido.Numero:D7}.xml", emitido.Xml);
```

Con `UruFactura.EntityFrameworkCore` ya queda guardado en la tabla `UruFacturaCfes`.

## Manejo de errores

```csharp
try
{
    var emitido = await client.EmitirAsync(cfe);
    var acuse = await client.EnviarAsync(emitido);
}
catch (CfeValidationException ex)        // el CFE no es válido (no se consumió número)
{
    Console.Error.WriteLine(string.Join(Environment.NewLine, ex.Errors));
}
catch (CaeException ex)                  // no hay CAE vigente con números para el tipo
{
    Console.Error.WriteLine(ex.Message);
}
catch (DgiCommunicationException ex)     // red, timeout, SOAP Fault o HTTP sin acuse
{
    Console.Error.WriteLine($"Error de comunicación con la DGI [{ex.CodigoRespuesta}]: {ex.Message}");
}
```

<Aside type="note">
  Si el envío falla por comunicación, el CFE ya está emitido y registrado: reintentá `EnviarAsync(emitido)` con el mismo objeto (o recuperándolo del almacenamiento). No lo vuelvas a emitir: consumiría otro número.
</Aside>

Ver [Códigos de respuesta DGI](../../reference/dgi-codes/) para la lista completa de estados.
