Esta guía cubre el proceso oficial de la DGI para habilitar la emisión de CFEs en producción.

## Resumen del proceso

```
Inscripción → Certificado Digital → Solicitar CAE → Homologación → Producción
```

---

## 1. Inscripción como emisor electrónico

<Steps>

1. Ingresar a [DGI en línea](https://www.dgi.gub.uy/) con usuario y contraseña del contribuyente.

2. Ir a **Gestión CFE → Inscripción como Emisor Electrónico**.

3. Completar los datos de la empresa y los tipos de CFE a emitir.

4. Esperar la aprobación de DGI (generalmente días hábiles).

</Steps>

<Aside type="note">
  **Normativa:** [Resolución 798/012 y modificativas](https://www.dgi.gub.uy/)
</Aside>

---

## 2. Obtener certificado digital

El certificado debe ser:
- Formato **X.509** en archivo `.p12` / `.pfx`
- Emitido por una **CA reconocida por AGESIC**
- Vinculado al **RUT del emisor**

### Proveedores habilitados

| Proveedor | Contacto |
|-----------|----------|
| ABITAB | [abitab.com.uy](https://www.abitab.com.uy/) |
| Correo Uruguayo | [correo.com.uy](https://www.correo.com.uy/) |
| CertiSur | [certisur.com](https://www.certisur.com/) |

### Configurar en el SDK

```csharp
var config = new UruFacturaConfig
{
    RutaCertificado     = "/ruta/certificado.p12",
    PasswordCertificado = Environment.GetEnvironmentVariable("CERT_PASSWORD")!,
    // ...
};
```

<Aside type="caution">
  Nunca almacenes `PasswordCertificado` en el código fuente o en repositorios.
</Aside>

---

## 3. Solicitar el CAE

<Steps>

1. Ingresar a DGI en línea → **Gestión CFE → Solicitud de CAE**.

2. Seleccionar el tipo de CFE (ej: e-Ticket 101).

3. Indicar la cantidad de comprobantes necesarios.

4. DGI devuelve el CAE con su número de autorización, serie, rango y fecha de vencimiento.

5. Registrar en el SDK:

   ```csharp
   await client.RegistrarCaeAsync(new Cae
   {
       NumeroAutorizacion = "90110001945",   // CAE_ID entregado por la DGI
       TipoCfe            = TipoCfe.ETicket,
       Serie              = "A",
       RangoDesde         = 1,
       RangoHasta         = 1000,
       FechaVencimiento   = new DateOnly(2027, 12, 31),
   });
   ```

</Steps>

---

## 4. Homologación (ambiente de pruebas)

La DGI exige un proceso de homologación antes de habilitar producción. UruFactura usa el endpoint de homologación automáticamente con `Ambiente.Homologacion`.

```csharp
var config = new UruFacturaConfig
{
    // ...
    Ambiente = Ambiente.Homologacion, // servicios de prueba de la DGI (puertos 6443 / 6460)
};
```

### Pasos de homologación

<Steps>

1. **Emitir los CFE de prueba requeridos** (tipos y cantidades según instructivo DGI):

   ```csharp
   var eticket = await client.EmitirAsync(new Cfe(TipoCfe.ETicket)
   {
       Detalle = [new LineaDetalle { NombreItem = "Servicio de prueba", Cantidad = 1, PrecioUnitario = 100m }],
   });

   var acuse = await client.EnviarAsync(eticket);
   Console.WriteLine(acuse.Recibido ? "✅ Sobre recibido (consultar el estado del CFE)" : $"❌ {acuse.Mensaje}");
   ```

2. **Enviar el Reporte Diario de prueba**:

   ```csharp
   // Resume los CFE firmados en la fecha (de Uruguay, no la del servidor)
   var reporte = await client.EnviarReporteDiarioAsync(HoraUruguay.Hoy());
   ```

3. **Consultar el estado** de cada CFE:

   ```csharp
   await client.ConsultarEnvioAsync(acuse);   // o client.ConsultarCfeAsync(eticket)
   Console.WriteLine($"Estado DGI: {eticket.EstadoDgi} {eticket.MensajeDgi}");
   ```

4. **Enviar un CFE con adenda.** La adenda no va a la DGI: viaja en el sobre al receptor electrónico, fuera de la firma.

   ```csharp
   var factura = await client.EmitirAsync(new Cfe(TipoCfe.EFactura)
   {
       Receptor = new Receptor { Documento = "214844360018", RazonSocial = "Cliente S.A.", Direccion = "Av. Italia 1234", Ciudad = "Montevideo" },
       Detalle  = [new LineaDetalle { NombreItem = "Servicio de prueba", Cantidad = 1, PrecioUnitario = 100m }],
       Adenda   = "Orden de compra: OC-123",
   });
   await client.EnviarAsync(factura);                                // primero a la DGI
   var sobre = await client.GenerarSobreReceptorAsync([factura]);    // luego al receptor (sobre.NombreArchivo)
   ```

5. **Pruebas de intercambio**: recibir sobres de otros emisores, devolver sus acuses y leer los del receptor.

   ```csharp
   var recibido = await client.RecibirSobreAsync(xmlSobre, nombreAdjunto);   // ACKSobre en recibido.XmlAcuse
   var respuesta = await client.ResponderCfesAsync(recibido);                // ACKCFE en respuesta.Xml
   var acuseReceptor = client.LeerAcuseReceptor(xmlAckSobre);
   var estado = client.LeerRespuestaReceptor(xmlAckCfe);
   ```

6. **Notificar a DGI** la finalización de las pruebas vía portal DGI en línea.

</Steps>

---

## 5. Habilitación en producción

Una vez aprobada la homologación por DGI:

```csharp
var config = new UruFacturaConfig
{
    // ...
    Ambiente     = Ambiente.Produccion,
    // En Producción no hay URL por defecto: usá las que entrega la DGI al habilitar el ambiente
    UrlEnvio     = "https://…/ws_efactura",
    UrlConsultas = "https://…/ws_consultas",
    UnidadIndexada = new Dictionary<int, decimal> { [2025] = 6.3m },   // UI al 31/12 de cada año: obligatoria en Producción
};
```

<Aside type="tip">
  Hacé un envío de prueba con un comprobante de bajo monto para validar el flujo completo antes de operar normalmente.
</Aside>

## Obligaciones operativas continuas

| Obligación | Periodicidad |
|-----------|-------------|
| **Reporte Diario** | Diario (obligatorio aunque sea 1 CFE); reenviarlo corregido si la DGI rechaza después un CFE del día |
| **Envío al receptor electrónico** | Con cada e-Factura, e-Remito o e-Resguardo a un cliente emisor electrónico, después de enviarlo a la DGI (la e-Boleta de entrada no se envía al vendedor) |
| **Respuesta a proveedores** | Con cada sobre recibido: acuse del sobre y respuesta a cada comprobante |
| **Unidad Indexada** | Cada año, antes del 1° de enero, agregar a `UnidadIndexada` la UI al 31/12 del año que termina |
| **Resguardo de XML** | Conservar 5+ años |
| **Renovar CAE** | Antes del vencimiento o agotamiento |
| **Renovar certificado** | Cada 1-3 años (según proveedor) |

| Ambiente | Servicio | URL |
|---------|----------|-----|
| Homologación | Envío (`ws_efactura`) | `https://efactura.dgi.gub.uy:6443/ePrueba/ws_eprueba` |
| Homologación | Consultas (`ws_consultas`) | `https://efactura.dgi.gub.uy:6460/ePrueba/ws_consultasPrueba` |
| Producción | ambos | Configurar `UrlEnvio` y `UrlConsultas` con las URL que entrega la DGI al habilitar el ambiente |

## Flujo completo en producción

```csharp
// 1. Configurar (en producción, con un almacenamiento durable: ver Gestión de CAE)
var config = new UruFacturaConfig
{
    Emisor = new Emisor
    {
        Rut             = "219999820013",
        RazonSocial     = "Mi Empresa S.A.",
        DomicilioFiscal = "Av. 18 de Julio 1234",
        Ciudad          = "Montevideo",
        Departamento    = "Montevideo",
    },
    Ambiente            = Ambiente.Produccion,
    UrlEnvio            = "https://…/ws_efactura",    // obligatorias en Producción:
    UrlConsultas        = "https://…/ws_consultas",   // las entrega la DGI
    RutaCertificado     = "/ruta/certificado.p12",
    PasswordCertificado = Environment.GetEnvironmentVariable("CERT_PASSWORD"),
};

using var client = new UruFacturaClient(config, store: miStoreDurable);

// 2. Emitir: valida, numera, firma y registra
var eticket = await client.EmitirAsync(new Cfe(TipoCfe.ETicket)
{
    Detalle = [new LineaDetalle { NombreItem = "Servicio de consultoría", Cantidad = 1, PrecioUnitario = 5000m }],
});

// 3. Enviar: acuse del sobre (AS / BS)
var acuse = await client.EnviarAsync(eticket);
if (!acuse.Recibido)
    throw new Exception($"DGI rechazó el sobre: {acuse.Mensaje}");

// 4. Resultado del comprobante
await client.ConsultarEnvioAsync(acuse);
if (!eticket.AceptadoPorDgi)
    throw new Exception($"DGI no aceptó el CFE ({eticket.EstadoDgi}): {eticket.MensajeDgi}");

// 5. Representación impresa (paquete UruFactura.Pdf)
await File.WriteAllBytesAsync("eticket.pdf", CfePdf.GenerarA4(eticket));
```

## Códigos de respuesta DGI

| Estado | Mensaje | Significado |
|--------|---------|-------------|
| `AS` | `ACKSobre` | Sobre recibido (no implica que los CFE hayan sido aceptados) |
| `BS` | `ACKSobre` | Sobre rechazado: ver los motivos (`S01`…`S20`) en `acuse.Motivos` |
| `BA` | `ACKSobre` / `ACKRepDiario` | Archivo rechazado |
| `AR` | `ACKRepDiario` | Reporte diario recibido |
| `BR` | `ACKRepDiario` | Reporte diario rechazado |
| `AE` | `ACKCFE` | Comprobante aceptado |
| `BE` | `ACKCFE` | Comprobante rechazado (CFE): motivos en `cfe.MensajeDgi` y `EstadoEnvio.Comprobantes[i].Motivos` |
| `CE` | `ACKCFE` | Comprobante observado (CFC) |
| `FE` | `ACKCFE` | Comprobante reliquidado |

<Aside type="note">
  Los errores de comunicación no son estados: un SOAP Fault (p. ej. firma WS-Security inválida) o una respuesta HTTP sin acuse (proxy, servicio caído) se lanzan como `DgiCommunicationException`, con `CodigoRespuesta` = `SOAP_FAULT` o el código HTTP.
</Aside>

Ver [Códigos DGI completos](../../reference/dgi-codes/) para más detalles.
